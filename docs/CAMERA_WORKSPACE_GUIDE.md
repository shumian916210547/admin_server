# 摄像头独立模块使用指南

摄像头管理作为独立模块提供四个页面，与平台「系统管理」并列：

| 页面 | 地址 | 功能 |
| --- | --- | --- |
| 组织管理 | `/camera/organizations` | 公司 → 组织 → 门店树、编码、排序、修改上级、启停和删除空节点。 |
| 设备管理 | `/camera/devices` | 扫描/手动关联、增删改查、组织归属、关键词/组织筛选、最多100台批量归属、封面、实时预览和两种录像回放。 |
| 成员管理 | `/camera/members` | 关联同企业账号或创建视频查看账号，设置归属组织、是否包含下级、授权状态、备注，移除视频授权。 |
| 视频中心 | `/camera/video` | 左上组织树、左下设备列表，右侧1–16分屏、拖拽设备、放大、暂停/恢复、全屏、断线重试及个人监控视图。 |

旧 `/system/camera` 深链接会跳转到设备管理。迁移保留原设备 Route 的 objectId、`system.camera` systemKey 及岗位权限关联，避免复制权限记录；新增三个页面在岗位管理中独立配置。

## 部署与升级

```powershell
cd admin_server
npm run migrate:camera
npm start
```

`migrate:camera` 按文件名执行幂等迁移，新增私有 `camera.organizations`、`camera.members`、`camera.views`、`camera.audit` 表和设备 `organization_id` 字段；不改变平台 Organization 的字段或已有数据，不删除录像。组织/设备/成员外键同时包含 `company_id`，防止跨租户归属。

管理员刷新菜单或重新登录后，系统补齐摄像头模块。旧设备没有归属时显示「未分配组织」，仅系统管理员可维护；请在设备管理中批量归属，再给普通成员配置视频组织授权。已有账号的原平台岗位不会被自动替换，需在岗位管理中分配所需视频页面和按钮。

在原 IPC 配置之外增加：

| 配置 | 默认值 | 范围与用途 |
| --- | --- | --- |
| `CAMERA_MAX_LIVE_STREAMS` | `32` | 16–128，单 BFF 进程的实时预览/设备回放并发额度，与录像额度独立。 |
| `CAMERA_MAX_STREAMS` | `8` | 1–64，现在用于服务器录像任务数。 |

每个独立预览槽位占一条实时任务，16分屏需要16条可用额度。浏览器一次最多并行启动四个连接，已播放的 HLS 不进入启动队列；流畅档输出最多640像素、12fps，标准档最多1280像素、20fps。实际16路高清设备的解码性能取决于CPU、设备主/子码流及网络，请先做容量评估。单 BFF、无音频、本地协议和录像保留策略仍遵循 [IPC 接入指南](IPC_CAMERA_GUIDE.md)。

## 组织管理

1. 从「新增公司」创建根节点，可填写名称、唯一编码、排序和备注。
2. 选中公司后「新增下级」创建组织。组织可以再建组织或门店，门店必须属于组织且不能再有子节点。
3. 编辑时可更名、修改上级或排序。前端排除自身/后代的上级选项，后端通过同企业事务锁再次检查类型与环路，防止并发移动形成循环。
4. 停用节点会使其下级普通成员失去对应视频访问；平台系统管理员仍可维护和恢复。已有服务器录像任务不会因组织停用自动停止。
5. 删除仅适用于没有下级、设备或成员引用的空节点。需要先迁移归属再删除，操作会有中文确认。

摄像头业务的三种组织类型与平台「总部/区域/地方公司/部门」模型不同，因此使用独立树；两者共同受到当前平台 Company 租户边界约束。

## 设备管理

1. 扫描或手动新增设备时必须选择归属视频组织，并填写本地账号、协议端口和RTSP相对路径。
2. 用名称、IP、安装位置关键词或组织（含下级）筛选设备；历史未归属设备可勾选「仅看未分配设备」。
3. 勾选最多100台，点击「批量归属」，确认访问范围影响后原子迁移；包含不可访问设备时整批不修改。
4. 修改名称、安装位置等元数据不会主动重启媒体；更换连接、密码或录像开关时会释放旧任务并由后台恢复录像。修改归属后，原组织成员的后续媒体请求立即按新范围校验。
5. 设备新增、修改、解除关联、组织/成员授权及批量归属写入脱敏审计，在「操作记录」中查看最新100条；服务端每企业保留最多10000条。记录不保存设备密码、URL凭据或成员初始密码。

实时预览、服务器MP4回放、Profile G/海康/大华SD卡或NVR回放操作不变，入口集中于设备管理。

## 成员管理

1. 「新增视频成员 → 关联现有账号」支持按账号/姓名搜索本企业启用成员，填写归属组织与授权状态。
2. 「创建视频账号」填写新账号、姓名及至少12位初始密码。系统创建同租户平台账号，自动分配最低权限的「视频查看成员」岗位，只授予视频中心查询权限，不赋予平台管理权限。
3. 「包含全部下级」表示可以看见归属组织及其启用后代的设备；关闭后仅允许归属组织的直属设备。
4. 编辑归属、范围和状态前需要确认权限影响。移除成员只撤销视频组织授权，保留平台账号及其他业务数据；可以重新关联。

权限同时满足两道条件：平台岗位已分配对应页面/操作，且摄像头成员在启用组织范围内。普通账号未配置视频成员关系时没有设备访问；组织停用、成员停用/移除或设备迁移后，旧播放URL不能绕过新范围。平台系统管理员按租户拥有维护权限。为防止委派越权，视频成员写入和企业账号选项目前只允许平台系统管理员执行。

## 视频中心

1. 左上可搜索组织树并选择节点；左下显示该组织的可见设备，可切换「含下级」并按设备名称/IP搜索。
2. 右上选择1至16中的任意分屏数。先选中目标画面，再点击左侧设备；也可把设备拖入某一画面。点击「播放当前组织」填充前N台设备，N为当前分屏数。
3. 每屏显示名称、组织、连接/播放/异常状态，提供重连、放大、移除。双击画面也可放大；「返回多画面」恢复布局。缩减分屏会释放超出槽位的流，再扩展时可恢复保留的分配。
4. 「全部暂停」会释放连接，恢复时进入启动队列。网络或解码故障最多自动重试三次（2/4/8秒）；权限失效、设备不存在和并发额度错误不无限重试，最终失败会显示在画面中。
5. 「中心全屏」使用浏览器全屏。窄屏下组织/设备区域位于画面区上方，工具栏换行，保持分屏数选择和画面操作可达。
6. 「保存视图」保存当前个人分屏和设备位置，最多20个；同名覆盖与删除有中文确认。视图不保存播放URL和密码，恢复时会按当前权限移除不可访问的设备。
7. 离开或关闭视频中心会释放全部播放器、后端流和排队任务；返回页面不自动恢复旧连接，避免后台持续消耗资源。

## 验证

```powershell
cd admin_server
npm run check
npm run security:check
npm run test:camera
# 安装本机FFmpeg和MediaMTX测试源，并先构建生产前端：
cd ../vue_admin
npm run build
cd ../admin_server
$env:CAMERA_TEST_MEDIAMTX="C:/tools/mediamtx.exe"
$env:CAMERA_TEST_BROWSER="1"
npm run test:camera
```

自动回归使用隔离Company和模拟摄像头源，不扫描现场网络或使用真实账号。浏览器模式将生产构建与测试BFF放在同一临时源，全部请求真实经过HTTP与权限中间件，不拦截API。额外覆盖组织表单、成员授权、逐一切换1–16分屏、16个独立通道同时HLS解码且播放时间持续前进、个人视图、全屏、窄屏、整页刷新与启动中离页释放。仍需用实际型号、分辨率及设备数量完成现场容量与兼容性验收。
